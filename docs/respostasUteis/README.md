# Respostas úteis

[← Documentação](../README.md)

Respostas de cunho **metodológico e conceitual** guardadas para releitura: o raciocínio por trás de uma decisão, não o passo a passo do que foi feito.

A divisão com o resto da documentação é esta:

| Onde | O que guarda |
|---|---|
| [`automation/07-log-de-execucao.md`](../automation/07-log-de-execucao.md) | **o que** mudou, com comando e saída literal — o registro operacional |
| [`science/02-defeitos...`](../science/02-defeitos-que-alteram-resultado.md) | **qual** é o defeito, onde está e que número ele afeta |
| **aqui** | **por que** — o raciocínio, os trade-offs, o que se aprendeu |

Um documento entra aqui quando responde a uma pergunta que vai voltar: *por que este conjunto e não outro*, *por que fixar a semente não basta*, *por que este método fica apesar de violar seus pressupostos*.
